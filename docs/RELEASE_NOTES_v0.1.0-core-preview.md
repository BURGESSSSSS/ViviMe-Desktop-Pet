# v0.1.0-core-preview 发布说明草案

这是维维美桌宠核心技术的首个预览版，包含可独立构建的 Java 17 工程和 Windows Swing 示例。

- 原创几何角色可拖动、落地及沿示例窗口顶沿行走。
- 核心模块有办公活动区、动作策略、窗口边缘判断、位置存档、程序音效和目标锁定。
- 命中示例完整播放六次程序绘制的索敌及命中效果。
- 构建与测试入口见 [BUILD.md](../BUILD.md)。源码遵循 GPL-3.0，保留 Ark-Pets 及第三方作者署名。

公开范围以通过审核的源码树为准。个人完整版 `ViviMePet v1.0.2`、其 Windows 安装包、受限运行时和游戏资源排除在本版本范围之外。

建议使用标签 `v0.1.0-core-preview`，指向私人仓库验证通过且授权对外发布的提交。此文件为本地草案。
